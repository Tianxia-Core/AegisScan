# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `2.0.x` | Yes |
| `< 2.0.0` | Upgrade to `v2.0.0+` |

## Reporting a Vulnerability

Report false-negative bypasses or security defects privately to **[Encrypted Security Dispatch](https://rasaxmachina.com/collins#encrypted-dispatch)**. Do not open public issues containing live exploit payloads or real credentials.
